# TNN Project by Team40
This repository holds all code for the ASL2024 project of our team.

### Structure
- ```TAB/``` contains the baseline implementations of TNN provided by the TA
- ```measurement/``` holds the code for our measurement infrastructure
- ```optimization/``` all optimizations that our team has done can be found here
- ```plots/``` functions used to generate our plots
- ```data/``` contains the raw data that we used to generate the plots
- ```rooflines/``` has the relevant data for the roofline plots
