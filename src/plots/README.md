## Plot Generation Overview
All information for generating plots can be found in the corresponding python files. Make sure that the relevant dependencies are installed. When generating plots, look for the configuration section inside the ```main``` function. Specify the processor frequency and the multiplication factor (for NANOS, MICROS, MILLIS) depending on what was used during measuring. Paste the input sizes, measurements and compute the cost of the computation. Then, specify the indices for which the speedup is calculated. After writing the plot generation function, set the corresponding variable and run the code. The plots are stored to ```plots/``` by default.
